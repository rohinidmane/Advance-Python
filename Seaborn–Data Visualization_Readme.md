# 📊 Seaborn – Data Visualization with Python

A Python programming project that introduces **Seaborn**, a Python library used for creating attractive statistical visualizations. This project covers different plots using the built-in Tips dataset.

---

## 📊 What This Project Does

This project demonstrates basic data visualization using Seaborn.

It helps to understand:

- Importing Libraries
- Loading the Tips Dataset
- Data Inspection
- Scatter Plot
- Line Plot
- Bar Plot
- Histogram
- Box Plot
- Pair Plot
- Heatmap
- Violin Plot

## 📊 Dataset Information

**Dataset Name: Tips Dataset**

A built-in Seaborn dataset containing restaurant bill, tip, customer, and dining information.

Important Columns:

| Column       | Description       |
| ------------ | ----------------- |
| `total_bill` | Total bill amount |
| `tip`        | Tip amount        |
| `sex`        | Gender            |
| `day`        | Day of the week   |
| `time`       | Lunch or dinner   |
| `size`       | Group size        |

## 🧠 Key Concepts Covered

**1. Loading Dataset**

Using `sns.load_dataset()` to load the Tips dataset.

**2. Data Inspection**

Using `head()`, `info()`, and `columns`.

**3. Statistical Visualization**

Creating Scatter, Line, Bar, and Histogram plots.

**4. Distribution Analysis**

Using Box Plot and Violin Plot to understand data distribution.

**5. Pair Plot**

Visualizing relationships between numerical variables.

**6. Heatmap**

Using `corr()` and `sns.heatmap()` to visualize correlations.

## 📈 Visualizations Performed

| Operation           | Purpose                       |
| ------------------- | ----------------------------- |
| `sns.scatterplot()` | Show relationships            |
| `sns.lineplot()`    | Display trends                |
| `sns.barplot()`     | Compare categories            |
| `sns.histplot()`    | Show data distribution        |
| `sns.boxplot()`     | Show data spread              |
| `sns.pairplot()`    | Show pairwise relationships   |
| `sns.heatmap()`     | Visualize correlations        |
| `sns.violinplot()`  | Show distribution and density |
| `corr()`            | Calculate correlation         |
