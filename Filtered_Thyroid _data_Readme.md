# 📊 Thyroid Data Analysis using Python

## 📌 Overview

A data analysis project using the Filtered Thyroid Dataset to explore patient information, understand dataset structure, identify missing values, and analyze different data attributes.

The project uses Pandas and NumPy to perform data inspection, filtering, and grouping operations.

## 🔄 Workflow

      ↓
Column and Data Type Inspection
      ↓
Missing Value Analysis
      ↓
Statistical Summary
      ↓

      ↓
Grouping and Counting
      ↓
Data Analysis

## 📊 Data Analysis

The project performs the following operations:

- Dataset Inspection: Checking dataset information, columns, and data types.
- Unique Values: Identifying unique values in the Pathology column.
- Value Counting: Counting records with Micropapillary pathology.
- Missing Value Analysis: Identifying null values using `isna().sum()`.
- Statistical Summary: Exploring numerical data using `describe()`.
- Data Filtering: Selecting records based on Age conditions.
- Grouping: Grouping patient records by Age and counting observations.

## 🚀 Key Learning

This project demonstrates how to explore and analyze a dataset using Pandas, apply filtering conditions, identify missing values, calculate descriptive statistics, and perform grouping operations.
