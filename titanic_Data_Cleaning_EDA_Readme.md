#  Data Cleaning and Preprocessing using Python

## 📌 Overview

A data preprocessing project using the Titanic Dataset to explore dataset information, identify missing values, handle inconsistent categories, and remove unwanted whitespace.

The project demonstrates basic data cleaning techniques using Pandas and NumPy.

## 🔄 Workflow

Dataset Loading
     ↓
Dataset Overview
     ↓
Missing Value Analysis
     ↓
Handling Inconsistent Categories
     ↓
Stripping Whitespace
     ↓
Cleaned Data

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Seaborn
- Jupyter Notebook

## 📊 Data Cleaning Techniques

- Dataset Overview: Checking dataset shape, information, and data types.
- Missing Value Analysis: Identifying missing values using `isnull().sum()`.
- Category Standardization: Converting inconsistent gender values into a consistent format.
- Whitespace Removal: Removing unwanted spaces using `str.strip()`.

## 🚀 Key Learning

This project demonstrates how to inspect datasets, identify missing values, standardize inconsistent categories, and clean text data using Python.
