## 📊 NumPy Concepts Covered

**1. Introduction to NumPy**

NumPy stands for Numerical Python. It is a general-purpose array-processing package used for numerical and scientific computing.

**2. Importing NumPy**

Using `import numpy as np` to import NumPy with the alias `np`.

**3. NumPy Version**

Using `np.__version__` to check the installed NumPy version.

**4. Array Creation**

Using `np.array()` to convert Python lists into NumPy arrays.

**5. Types of Arrays**

- **0-D Array:** A single scalar value.
- **1-D Array:** A simple collection of elements in one dimension.
- **2-D Array:** A matrix containing rows and columns.
- **3-D Array:** An array containing multiple 2-D arrays.

**6. Array Inspection**

Using NumPy attributes and functions to inspect and understand array structures.

**7. Array Shape**

Using `arr.shape` to identify the number of rows and columns in an array.

## 🧠 Types of NumPy Arrays

| Array Type | Description | Example |
|---|---|---|
| 0-D Array | Single value | `np.array(42)` |
| 1-D Array | One-dimensional array | `np.array([1, 2, 3])` |
| 2-D Array | Rows and columns | `np.array([[1, 2], [3, 4]])` |
| 3-D Array | Collection of 2-D arrays | `np.array([[[1, 2, 3]]])` |
