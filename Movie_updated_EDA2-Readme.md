# 🎬 Movies Dataset – Exploratory Data Analysis (EDA)

A Python data analysis project that explores a movies dataset using **Pandas, NumPy, Matplotlib, Seaborn, and Plotly**. This project analyzes movie genres, ratings, votes, budgets, gross revenue, and release years to identify popular movies and understand trends in the movie industry.

---

## 📊 What This Project Does

This project performs Exploratory Data Analysis (EDA) on a movies dataset.

It helps to understand:

- 🎭 Movie Genre Analysis
- ⭐ Movie Rating Analysis
- 🗳️ Vote Distribution
- 📅 Year-wise Movie Analysis
- 💰 Movie Budget Analysis
- 🏆 Top 50 Movies by Votes
- 🎬 Top 20 Movies by Votes
- 📈 Budget vs Movie Score Analysis
- 🔍 Identification of the Most Expensive Movie

## 🧠 Key Concepts Covered

**1. Basic Data Exploration**

Using `info()`, `columns`, and `describe()` to understand dataset structure, column names, and statistical summaries.

**2. Unique Values**

Using `unique()` to identify different movie genres.

**3. Data Filtering**

Filtering movies based on specific conditions:

- Adventure genre movies.
- Movies with a score greater than or equal to 7.3.
- Movies released in the year 2000.
- Movies with votes greater than or equal to 4400.

**4. Missing Values Analysis**

Using `isna().sum()` to identify missing values in the dataset.

**5. Grouping and Aggregation**

Using `groupby()` and `size()` to analyze movie records based on votes.

**6. Movie Genre Analysis**

Visualizing movie votes by genre using bar charts.

**7. Top Movies Analysis**

Identifying and visualizing the Top 50 and Top 20 movies based on total votes.

**8. Budget Analysis**

- Converting budget values into numeric format.
- Identifying the most expensive movie.
- Analyzing budget statistics.
- Visualizing the highest-budget movie.

**9. Budget vs Score Analysis**

Using a scatter plot to understand the relationship between movie production budgets and movie scores.
