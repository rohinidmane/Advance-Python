# 📊 Matplotlib – Data Visualization in Python

A Python data visualization project that demonstrates different types of charts and graphs using **Matplotlib and NumPy** to represent data visually and understand patterns, trends, and distributions.

---

## 📊 What This Project Does

This project demonstrates different visualization techniques to represent numerical and categorical data.

The following charts are created:

- 📈 Line Plot
- 📊 Bar Chart
- 🥧 Pie Chart
- 🔵 Scatter Plot
- 📉 Histogram
- 🖼️ Multiple Plots (Subplots)

## 📊 Types of Visualizations

| Visualization | Purpose |
|---|---|
| 📈 Line Plot | Shows trends and changes in data |
| 📊 Bar Chart | Compares different categories |
| 🥧 Pie Chart | Represents proportions and percentages |
| 🔵 Scatter Plot | Shows relationships between two variables |
| 📉 Histogram | Displays frequency distribution |
| 🖼️ Multiple Plots | Displays multiple charts in one figure |

---

## 🧠 Key Concepts Covered

**1. Line Plot**

Used to visualize data points connected by straight lines and identify trends.

**2. Bar Chart**

Used to compare different categories using rectangular bars.

**3. Pie Chart**

Used to represent data as proportions or percentages of a whole.

**4. Scatter Plot**

Used to identify relationships and patterns between two numerical variables.

**5. Histogram**

Used to understand the frequency distribution of numerical data.

**6. Multiple Plots**

Used to display multiple graphs in a single figure using subplots.
